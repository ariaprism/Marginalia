# Marginalia 技术与产品决定

## 2026-07-19：第一版阅读器改为分页优先

### 背景

施工地图最初计划第一版优先滚动阅读，到后续阶段再增加翻页模式。视觉讨论后，确认左右分页更符合 Marginalia 的纸质书隐喻和安静阅读体验。

### 决定

- Phase 1A 的视觉原型直接采用左右分页。
- Phase 1B 的真实 EPUB 阅读器以分页为主要阅读方式，不再把翻页推迟到 Phase 6。
- 页面左侧 40% 用于上一页，右侧 40% 用于下一页，中间 20% 用于唤起或收起阅读工具。
- 文字选择、已有划线和交互控件优先于翻页点击。
- 顶栏和五区底栏默认隐藏；正文内部平常不显示返回键。

### 影响

- EPUB 页码是当前窗口和排版设置下的动态页码，不能作为稳定定位依据。
- 阅读位置、划线与批注仍需保存结构定位、原文和上下文，改变字号后重新计算页码。
- Phase 1B 需要更早处理分页、跨元素选区和改变排版后的重锚定。

## 2026-07-19：Phase 1A 使用原创模拟样书

### 决定

视觉原型使用原创短篇《雨夜书房》和模拟批注，不依赖真实 EPUB、云端或 AI 接入。真实 EPUB 留到 Phase 1B 验证。

## 2026-07-19：书架与阅读入口分层

### 决定

- 手机书架使用混合卡片：封面与基本信息横排，最近停留独占下一行。
- 点击封面进入该书的“小房间”，集中展示简介、进度、最近停留、章节和痕迹。
- 点击书籍信息或“继续阅读”直接回到正文；点击最近停留直接跳到对应痕迹。
- 书架首页不再显示大幅宣传标题，使书籍成为首屏主体。

## 2026-07-19：排版变化必须触发真实重分页

### 决定

阅读正文保持连续内容流，并根据可用页面尺寸自动分栏。字号、行距、页边距或屏幕尺寸变化时重新计算页数，不得通过隐藏溢出内容维持固定页数。

## 2026-07-20：“最近停留”表示阅读位置

### 决定

- “最近停留”保存用户最后阅读时的章节、稳定正文定位、进度及附近原文预览。
- 返回书架、应用进入后台或页面关闭前，应保存当前阅读位置。
- 最近划线和最近批注是不同概念，不得用来替代最近停留。
- 点击最近停留应回到原阅读位置；排版变化后仍通过稳定定位找到同一句附近。

## 2026-07-20：不同入口采用不同痕迹顺序

- 书籍小房间作为全书地图，按章节顺序及原文位置顺序展示全部痕迹。
- 阅读器底栏作为最近活动入口，按创建时间倒序展示痕迹。
