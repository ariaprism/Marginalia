# v0.2 Living Book — Phase 1B 检查点

## 已实现

- 导入无 DRM EPUB，并解析元数据、封面、目录和 spine 章节。
- 导入前预览并修改书名、可选英文名、作者、简介与封面。
- 浏览器内动态分页，支持目录跳转和排版重算。
- 本地持久化书籍、EPUB、章节、阅读位置、折页、划线和多条批注。
- 书架状态、最近打开排序、置顶、读完／重温与完整删除。
- Locator 重锚定；详情页和痕迹面板跳到实际句子所在动态页。
- 真实 EPUB 章首去除重复目录标题；普通正文才启用首字下沉。

## 验收故事

在一个干净 Origin 中依次完成：

1. 看到空书房并从空状态进入藏书弹窗。
2. 选择 EPUB；确认预解析期间未写库，修改元数据后入库。
3. 打开书籍小房间，确认仍为“想读”；打开正文后转为“在读”。
4. 阅读长书并调整字号、行距、页边距和字体，当前位置及痕迹不漂移。
5. 留下折页、划线和多条批注；离开、刷新并重新打开后全部恢复。
6. 从目录和痕迹临时跳转，确认不会误写自动继续位置。
7. 到末页标记读完，再从头重温；痕迹和折页仍保留。
8. 删除书籍并确认所有关联本地数据消失。
9. 在桌面与约 390×844 手机视口重复关键路径。

## Phase 1B 明确非目标

- 不支持 DRM、PDF、OCR、TXT 或在线书源。
- 不调用 AI 模型，不提供即时聊天。
- 不做 Supabase、账户、跨设备同步、远端备份或多人共享。
- 不导入微信读书；影子书、来访、念头和云端书房只有说明壳。
- 不承诺完整保留 EPUB 原书 CSS、复杂脚注、媒体、交互脚本或固定版式。
- 不以动态页码作为稳定定位。
- 不提供恢复误删书籍的回收站。

## 已知边界

- 数据属于当前浏览器 Origin；`localhost`、局域网 IP 和 GitHub Pages 互不共享。
- 当前正文提取以可阅读纯文本为目标，不是完整 EPUB 排版引擎。
- 首字下沉依赖章节标题和 HTML 语义启发式；异常制作的 EPUB 可能需要兼容规则。
- `App.tsx` 已完成第一轮 feature 拆分；分页、Locator、痕迹和折页控制器仍待整体迁移。
